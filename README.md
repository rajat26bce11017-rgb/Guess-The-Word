# Guess-The-Word
A fun and interactive command-line Word Guessing (Jumbled Words) game built using Python. Unscramble the letters using the helpful hints provided to score points!

🌟 Features

Jumbled Words Mechanics: Randomly shuffles letters for each word every time you play.

Helpful Hints: Provides hints for every word to guide the player.

Scoring System: Gain +10 points for every word guessed correctly.

Multiple Attempts: Get up to 3 chances per word before revealing the correct answer.

Easy Exit Option: Type exit at any point during gameplay to quit and view your current score.

📋 Prerequisites

Before running the game, make sure you have Python 3.x installed on your system.
You can check if Python is installed by running the following command in your terminal or command prompt:

python --version
# or
python3 --version


Note: This game uses Python's built-in random module, so no external libraries or dependencies need to be installed.

🚀 How to Run the Game from GitHub

Follow these simple steps to run the game directly on your local machine:

1. Clone the Repository

Open your terminal or command prompt and clone this repository using Git:

git clone https://github.com/rajat26bce11017-rgb/Guess-The-Word

2. Navigate to the Project Directory

Change directory to where the project files are located:

cd Guess-The-Word


3. Run the Game

Execute the Python script using terminal:

On Windows:

python main.py


On macOS / Linux:

python3 VITYARTHIproject.py

🕹️ Game Rules

You will be shown a jumbled word alongside a hint.

Type your guess in the terminal and press Enter.

You have 3 chances to guess each word correctly.

Each correct guess adds 10 points to your total score.

You can quit the game anytime by typing exit.
